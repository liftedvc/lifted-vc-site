# Final Scripts

Paste-ready voiceover scripts for the Lifted Fundraising Playbook video series. Files in this folder contain just the script text plus minimal metadata (placement, length). Drop the script body straight into Golpo.

The fuller working versions, with AI voiceover notes and scoping rationale, live one folder up at `lifted-vc-site/scripts/`.

## Order (matches playbook flow)

1. `01_why-we-built-this-playbook.md` — Landing page hero
2. `02_how-to-use-this-playbook.md` — Introduction
3. `03_authentic-fomo-process.md` — Chapter 2, What Is Authentic FOMO?
4. `04_how-rounds-get-raised.md` — Chapter 2, The Anatomy of a Raise
5. `05_the-problem.md` — Chapter 3, Communicate Your Story → The Problem
6. `06_why-now.md` — Chapter 3, Communicate Your Story → Why Now

## Update flow

When a script changes:
1. Adam (or Claude) updates the page copy in `fundraising-playbook.html` if relevant
2. Claude updates the canonical script in `lifted-vc-site/scripts/`
3. Claude updates the matching final-script file in this folder
